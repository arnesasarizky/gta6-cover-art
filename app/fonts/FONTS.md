# Fonts

All three fonts in this folder are licensed under the SIL Open Font License,
Version 1.1 — the full license text is in `OFL.txt` beside them. The app loads
them only from these local files; it makes no network request for fonts.

| Font | File | Authors / source |
| --- | --- | --- |
| Anton | `Anton-Regular.ttf` | The Anton Project Authors — https://github.com/googlefonts/AntonFont |
| Pacifico | `Pacifico-Regular.ttf` | Vernon Adams — https://github.com/google/fonts/tree/main/ofl/pacifico |
| Bebas Neue | `BebasNeue-Regular.ttf` | Ryoichi Tsunekawa (Dharma Type) — https://github.com/google/fonts/tree/main/ofl/bebasneue |

No Rockstar Games font, logo, wordmark or artwork is used anywhere in this
entry. The lettering is Anton (titles), Pacifico (script subtitles) and Bebas
Neue (badges and labels) — all SIL OFL, all shipped under `app/fonts/`.
